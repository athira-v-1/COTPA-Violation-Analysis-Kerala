# COTPA Violation Analysis and Forecasting in Kerala

## Project Overview
This project analyzes violations of the Cigarettes and Other Tobacco Products Act (COTPA) in Kerala and predicts future violations of the most violated act, using Time Series Forecasting.

## Objectives
• Identify the most violated sections of COTPA  
• Analyze historical violation trends  
• Forecast future violations using ARIMA Time series model

## Dataset
The dataset contains:
- COTPA sections
- Number of persons fined
- Amount collected
- Violation records across 5 (January 2019 to December 2023) years

## Methodology
1. Data Cleaning and Preparation
2. Statistical Analysis
3. Identification of Most Violated Section
4. Time Series Analysis
5. Forecasting using ARIMA Model

## Tools Used 
• R Studio  
• Excel  
• Time Series Analysis

## Model Used
ARIMA (AutoRegressive Integrated Moving Average)

## Key Findings
• Section 4 had the highest violation rate.
• Time series analysis showed trends in violations.
• ARIMA model was used to forecast future violation patterns.

## Outcome
The model predicted future violations for the most violated COTPA section, helping to understand possible future enforcement trends.
